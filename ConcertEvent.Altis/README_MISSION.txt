Build this mission in the Eden Editor (the mission.sqm is created when you save):

1. Load the game with @ConcertMod enabled, open Eden on your map, save as "ConcertEvent".
2. Place screen objects, e.g. Land_TripodScreen_01_large_F
   Variable Names: concert_screen_1, concert_screen_2, ...
3. (Optional) Place speaker objects, e.g. Land_PortableSpeakers_01_F or any prop
   Variable Names: concert_speaker_1, concert_speaker_2, ...
   If none exist, the sound comes from the screens.
4. (Optional) Place a laptop, e.g. Land_Laptop_unfolded_F
   Variable Name: concert_control   -> admins get Start/Stop Concert actions
5. Place playable units, save, export to multiplayer.
6. Copy this description.ext into the saved mission folder.
